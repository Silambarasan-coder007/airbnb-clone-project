# Airbnb Clone

Airbnb home page + search results page built with HTML5, CSS3 (Flexbox, Grid, media queries) and vanilla JavaScript. Fully responsive.

**Live demo:** https://YOUR-USERNAME.github.io/REPO-NAME/  <!-- replace after deploying -->

## Features
- Search form (location, check-in/out, guests) with date validation; submits to the results page via URL params
- Results page shows the search summary, nights-based total prices (₹), sorting and a Filters dialog (type, amenities, max price)
- Wishlist hearts (saved in localStorage)
- Top-rated carousel with working arrows and page counter
- Map panel that jumps to a home when you select it
- Image fallback when a remote photo fails to load

## Files
`index.html` (home) · `search.html` (results) · `style.css` · `data.js` (sample listings + helpers) · `home.js` · `search.js`

## Run locally
Open `index.html` in a browser. Listing data is sample data.

## Deploy
Push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.
